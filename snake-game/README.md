# Snake Game Instructions

## How to Play
1. Open your terminal and navigate to the `snake-game` folder.
2. Run the game using python:
   ```bash
   python snake.py
   ```
3. Use the **Arrow Keys** (`Up`, `Down`, `Left`, `Right`) to control the snake.
4. Eat the red food to grow and increase your score.
5. Avoid hitting the walls or your own tail!
6. When you game over, press **R** to restart or **Q** to quit.
